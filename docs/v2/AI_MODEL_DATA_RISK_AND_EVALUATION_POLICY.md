# سياسة نموذج وبيانات ومخاطر AI

## الحدود التشغيلية

مساعد ZAMAM V2 هو **proposal-only**. ينشئ تلخيصات ومسودات ومقترحات قابلة للمراجعة، ولا ينفذ بنفسه حذفاً أو اعتماداً أو تغيير صلاحيات أو نشر Workflow أو قرار HR/مالي/أمني. تعطيل `AI_ENABLED` أو غياب إعداد المزود يغلق المسار دون تعطيل بقية النظام.

## البيانات

- يسمح افتراضياً بـ `operational_public` و`internal` فقط. `client_confidential` يحتاج سياسة مؤسسة صريحة، بينما `hr_sensitive` و`financial_sensitive` مرفوضان افتراضياً.
- تطبق `redactAIText` إزالة البريد والهاتف وأنماط الأسرار قبل إنشاء Outbox.
- لا تحفظ الخدمة النص الخام في `ai_request`؛ تحفظ `promptHash` وبيانات الغرض والتصنيف. حمولة العمل المنقحة قصيرة العمر ولا تسجل في Logs.
- مدة الاحتفاظ الافتراضية بالطلبات والنتائج 72 ساعة، وتزال بواسطة مهمة retention. تبقى قرارات الموافقة كـ `AuditEvent` وفق سياسة التدقيق.
- يمنع استخدام بيانات مؤسسة في تدريب المزود تعاقدياً وإعدادياً قبل تفعيل `live`.

## بوابة المزود

`AIGatewayJob` هو الحد الوحيد للمزود. يفرض مهلة 30 ثانية، وحد خرج 1000 token، وحد استخدام 5000 token للعملية، ويتحقق مجدداً من prompt injection. `DisabledAIProvider` هو الوضع الآمن الافتراضي، والاختبارات تستخدم Mock محلياً بلا اتصال خارجي.

## سلامة المقترحات

كل مقترح يحمل SHA-256 حتمية لـ `actionType` و`arguments`. قرار المراجع يتطلب `ai.action.approve` وstep-up ويعيد التحقق من البصمة ونسخة السجل. الموافقة لا تعني التنفيذ (`executed: false`)؛ أي تنفيذ مستقبلي يجب أن يمر بأمر Domain مستقل ويتحقق من صلاحية الإجراء المستهدف وحالته.

## التقييم

مجموعة التقييم المحلية الإلزامية تغطي: حجب الأسرار والمعرفات، prompt injection، غياب المزود، تجاوز الوقت/الاستخدام، ثبات البصمة، وهلوسة action غير معروف، وعدم وجود تنفيذ مباشر. معايير القبول: صفر تسريب في fixtures، وصفر تنفيذ عالي المخاطر، و100% من المقترحات قابلة للتتبع إلى request/model policy/hash.

## التشغيل والحوادث

عند تسريب مشتبه به: عطّل `AI_ENABLED`، أوقف consumer، احفظ metadata غير الحساس، ألغ بيانات اعتماد المزود خارج المستودع، وحدد الطلبات عبر hash/correlation ID. لا يعاد التشغيل قبل مراجعة النطاق وسياسة التصنيف. لا يمثل هذا المستند اعتماداً قانونياً؛ المراجعة القانونية شرط إطلاق.
